## Custom website theme

if you want to add you own color palletes then create a file in `static/css/themes/` and add your colors in the follwing pattern :

``` css
@media (prefers-color-scheme: dark /* either dark or light */ ) {
  :root {
    --base00: #1e1e2e; /* background */
    --base01: #181825; /* background shade 1 */
    --base02: #313244; /* background shade 2 */
    --base03: #45475a; /* background shade 3 */
    --base04: #585b70; /* background shade 4 */
    --base05: #cdd6f4; /* foreground and text */
    --base06: #f5e0dc; /* foreground shade 1(not used) */
    --base07: #b4befe; /* purple (not used) */
    --base08: #f38ba8; /* red */
    --base09: #fab387; /* orange */
    --base0A: #f9e2af; /* yellow */
    --base0B: #a6e3a1; /* green */
    --base0C: #94e2d5; /* teal */
    --base0D: #89b4fa; /* blue */
    --base0E: #cba6f7; /* voilet */
    --base0F: #f2cdcd; /* foreground shade 2 (not used)*/
  }
}
```
